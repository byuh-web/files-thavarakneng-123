Cambodia Photo Tour - Simple Version

This version was made to look like a beginner website while still matching the rubric.

Files:
- index.html
- angkor-wat.html
- bayon-temple.html
- ta-prohm.html
- royal-palace.html
- central-market.html
- style.css
- images folder for CSS background images and the custom bullet image

Rubric notes:
- 6 HTML pages total.
- Every page has header, nav, main, and footer.
- Header, nav, and footer use the same content and order on every page.
- The current page link is highlighted with the active class.
- The home page uses ul and li for the tour places.
- The CSS file uses two background images on the body: one repeating and one non-repeating.
- The tour list uses a custom image bullet.
- There is only one external CSS file.
- Place pages have 9 photos total.
- Angkor Wat and Ta Prohm each have 3 photos, so two pages have more than 2 photos.
- Photos use Wikimedia Commons links and source captions.
- No img tags use HTML width or height attributes.

Before submitting, upload the HTML and CSS to the official W3C validators if your teacher requires proof.
